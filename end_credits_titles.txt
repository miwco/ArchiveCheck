# Arcada end-credit titles — controlled vocabulary
#
# ArchiveCheck maps each role found in a film's credits to the closest title in
# this list, so the archive only ever stores approved titles.
#
# Format:
#   - One title per line, written as "Svenska / English".
#   - Blank lines and lines starting with "#" are ignored (use them for layout).
#   - The section headers below are comments for humans only — grouping is purely
#     for readability and does not affect how roles are matched.
#   - Edit freely: add, remove, or move titles. Keep a title's exact spelling, as
#     it is what gets written to the archive.
